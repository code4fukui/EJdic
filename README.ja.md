# EJdic - FastEJDic (英和辞典)

[EJdic](https://code4fukui.github.io/EJdic/)

## 機能
- CC-CEDICTデータに基づく英和辞典
- 即時検索と結果表示
- 漢字リンクによる素早い検索
- DeepLによる日本語翻訳

## データ / API
- データソース: CC BY-SA [CC-CEDICT Editor](https://cc-cedict.org/editor/editor.php?handler=Main)
- 日本語翻訳: [DeepLAPI](https://github.com/code4fukui/DeepLAPI)
